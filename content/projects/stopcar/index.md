智慧停车系统是一个 Linux C++ 服务端项目，采用前置网络服务与后置业务服务的双进程结构。前置服务负责 TCP 接入、协议解析和响应回写，后置服务负责业务任务分发、数据库读写和文件传输处理，两个进程之间通过共享内存、消息队列和信号量完成通信。

## 技术栈

- Linux / C++ / Socket / epoll / pthread
- 共享内存 / 消息队列 / 信号量
- MySQL / PreparedStatement
- 自定义二进制协议 / 文件分片传输

## 核心实现

- 基于 Socket 和 epoll 实现 TCP 接入，使用 service_type、data_len、body 组织业务请求。
- 通过任务工厂分发登录、车辆进出、车辆查询、记录查询、视频保存、文件传输和心跳等业务任务。
- 使用共享内存、消息队列和信号量传递请求、响应与客户端连接标识，解耦网络收发与后置业务处理。
- 实现应用层文件分片传输，基于分片序号、总片数、文件大小完成缓存去重、缺片检测、缺片反馈与按序重组。

## 面试可讲点

这个项目最适合重点讲“服务端链路”和“文件分片传输”。协议层定义了固定协议头，业务类型和数据长度先被前置服务解析，再通过 IPC 交给后置任务处理。文件传输部分不是一次性发送大文件，而是每个分片携带序号和总片数，服务端能检查缺片并反馈需要补传的分片。

源码中定义了 13 个协议类型编号，任务工厂实际分发 11 类业务请求。因此更稳妥的表述是“定义协议类型并完成核心业务任务分发”，不要夸成完整生产级 TCP 拆包框架。
